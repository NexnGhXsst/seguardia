Welcome to S3-Guardian – your automated backup solution for Docker volumes. Secure, simple, and reliable.

Get Started

Features

🔄

Automatic

Scheduled backups without manual intervention. Set it up once, run forever.

☁️

S3-Compatible

Works with AWS S3, Cloudflare R2, Backblaze B2, MinIO and all S3-compatible storage.

📦

Smart Compression

Intelligent tar.gz compression with configurable levels for optimal storage usage.

🧹

Auto-Cleanup

Automatic deletion of old backups after configurable retention period.

🐳

Sidecar Pattern

Runs alongside your main application without performance impact or interference.

🔒

Secure

Read-only volume mounts and non-root user for maximum security.

Quick Start

Add S3-Guardian to your docker-compose.yml:

version: '3.8'

services:
  your-app:
    image: your-app:latest
    volumes:
      - app_data:/data

  s3-guardian:
    image: ghcr.io/nexnghxsst/seguardia:latest
    environment:
      AWS_ACCESS_KEY_ID: ${AWS_ACCESS_KEY_ID}
      AWS_SECRET_ACCESS_KEY: ${AWS_SECRET_ACCESS_KEY}
      S3_BUCKET: my-backups
      S3_ENDPOINT_URL: https://your-account.r2.cloudflarestorage.com
      TARGET_PATH: /data
      BACKUP_INTERVAL: 6h
    volumes:
      - app_data:/data:ro
    restart: unless-stopped

volumes:
  app_data:

Start with a simple command:

docker-compose up -d

Configuration

All settings are controlled via environment variables:

Variable Status Default Description
AWS_ACCESS_KEY_ID Required - S3/R2 Access Key
AWS_SECRET_ACCESS_KEY Required - S3/R2 Secret Key
S3_BUCKET Required - Bucket name
TARGET_PATH Required - Path to backup
S3_ENDPOINT_URL Optional - For R2/B2/MinIO
BACKUP_INTERVAL Optional 6h Backup frequency (30m, 1h, 6h, 1d)
RETENTION_DAYS Optional 30 Days until deletion
COMPRESSION_LEVEL Optional 6 Compression (1-9)

Examples

Minecraft Server

s3-guardian:
  image: ghcr.io/nexnghxsst/seguardia:latest
  environment:
    S3_BUCKET: minecraft-backups
    TARGET_PATH: /data
    BACKUP_INTERVAL: 6h
  volumes:
    - minecraft_data:/data:ro

PostgreSQL Database

s3-guardian:
  image: ghcr.io/nexnghxsst/seguardia:latest
  environment:
    S3_BUCKET: db-backups
    TARGET_PATH: /var/lib/postgresql/data
    BACKUP_INTERVAL: 12h
    RETENTION_DAYS: 90
  volumes:
    - postgres_data:/var/lib/postgresql/data:ro
